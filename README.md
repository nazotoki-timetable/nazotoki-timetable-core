# Universal Timetable Core (v2.0)
謎解きフェス・イベント特化型 ハシゴ計画＆タイムテーブルシミュレーター

本リポジトリは、謎解きフェスやイベントで「参加者がチケット争奪戦前に最適なハシゴ計画を立てる」ための高機能Webシミュレーターの**公式親テンプレート**です。

---

## 🚀 主な機能・特徴

1. **現場特化型ファジーパーサー**:
   - 制作団体の自由記述（「約60分」「40〜50分」「★3」「中級」「SOLD OUT」など）を賢く自動解釈。
2. **完全オフライン＆モック自動フォールバック**:
   - ローカル起動時やGAS未接続時でも、内蔵サンプルデータですぐに全機能が動作。
3. **データアダプター設計（疎結合）**:
   - Googleスプレッドシート（GAS）だけでなく、ローカルJSON、将来の「Escape ID API」連携にも柔軟に対応可能。
4. **高品位UI / UX**:
   - ガントチャート型タイムテーブル、チケットパス風ハシゴテーブル（漆黒背景＋ネオンパープル）、難易度ステッパー＆機会均等タグ検索、バッティングリアルタイム警告。
5. **GitHub Actions 完全自動デプロイ**:
   - コードを変更してプッシュするだけで、GitHub Pagesが自動ビルド＆公開。

## 🛠️ 開発・ローカル起動

### 前提要件
- Node.js (v18以上推奨)

```bash
# 依存パッケージのインストール
npm install

# ローカル開発サーバー起動 (ホットリロード対応)
npm run dev

# プロダクションビルド
npm run build

# ビルド成果物のローカルプレビュー
npm run preview
```

---

## 🎪 次回フェス（新イベント）の立ち上げ手順

1. 本リポジトリ右上の **「Use this template」**（テンプレートとして使用）をクリックし、新リポジトリ（例: `saienfes17`）を作成。
2. Googleスプレッドシートのテンプレートをコピーし、公演データを入力。
3. 発行されたGASのWebアプリURLを `index.html` または `?api=...` クエリとして指定。
4. `git push origin main` を実行すると、GitHub Actionsが自動的にWebサイトを公開します。
