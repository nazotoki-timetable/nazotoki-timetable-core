# 汎用タイムテーブル・ハシゴ計画テンプレート (Universal Timetable Core v3.0)

イベント・謎解きフェスティバル向けのタイムテーブル＆ハシゴ計画作成 Web アプリテンプレートです。Google スプレッドシートと組み合わせてノーコードでデータ更新・カラー着せ替え・公開運用ができます。

## 主な特徴 (v3.0 バニラ版)

- **直感的ファーストビュー**: 上部は `[使い方]`・`[< DAY N >]`・`[絞り込み・便利機能]` の 1 行のみ。時間枠をタップすると下部選択バーがせり出し、`自分の予定・ハシゴ表を見る` へ自然に誘導します。
- **時間重複・0分移動チェック**: スプレッドシートの `0分移動可否` 設定に応じて重複を赤色警告し、確認ダイアログ内でそのまま調整できます。
- **スキマ時間探索（Now Loading 演出付き）**: `スキマ時間に入れる公演を探す` を押すとナゾトキあるある待機メッセージを表示した後、`0分移動NG` 時は前後各 5 分以上の余裕がある候補を自動提案します。
- **My ハシゴテーブル書き出し＆共有**: パス形式の高解像度 PNG 保存、`予定をコピー`（`?plan=` 共有リンク付）、`Xでシェア` に対応。共有リンク閲覧時は端末内の保存予定を上書きせず保護します。
- **Google フォーム連携（GAS）**: 出展団体向け登録フォーム自動生成と、`1.公演かんたん入力` シートへの取り込み・GitHub JSON 同期に対応します。
- **効果測定・利用レポート（人気タグ集計＆GA4連携）**: Web 側の UI を変えずに、アクセス人数・ハシゴ作成人数・平均選択公演数・スキマ探索/画像保存/Xシェア回数・人気タグランキング・公演別組込数をスプレッドシートの `利用レポート` シートへ自動集計します（`設定` シートの `効果測定GAS URL` / `GA4測定ID` に対応）。

```bash
npm install
npm run dev
```

## データ設定（Google スプレッドシート / JSON）

- `public/data.json`（およびフォールバック用 `public/mock_data.json`）から高速読み込み（SWR）を行います。
- URL クエリ `?api=<GAS_URL>` で Google Apps Script API へ接続、`?mock=1` でモックデータ表示が可能です。
- イベント単位の着せ替えは JSON の `config` 内 `タイムテーブルメインカラー` / `タイムテーブルアクセントカラー`、および `0分移動可否`（`0分移動NG` / `0分移動OK`）で切り替わります。
- スプレッドシートの「1.公演かんたん入力」シート E 列 `開始時間リスト` は以下の 3 パターンに対応しています：
  - **複数回の通常公演**: `10:30, 12:00, 13:30`（カンマ・読点・改行区切り、全角数字は自動変換）
  - **終日の随時受付**: `随時`
  - **休止時間を挟む随時受付**: `10:00-12:00, 13:00-18:00`（「開始-受付終了」のレンジ記法。12:00〜13:00 を休止空白とした 2 枠へ自動展開されます）

## 設計思想

「見ずに触れそう・触ってみたら使い方がわかる」**初心者フレンドリーさ**と、**すべての出展団体の作品・ビジュアルに平等にスポットライトが当たるフェス全体の回遊体験**を軸に設計しています。

- **迷わせない極簡ファーストビュー**: 初期画面の情報は時刻とビジュアルに絞り、「3行で説明できない機能」や過剰なボタンは置かず視線誘導で次の一手を示します。
- **機会均等・ビジュアル重視**: 有名団体の狙い撃ちだけで終わらないよう、団体名フィルター・列非表示・極小テキスト化は設けず、タグ順の毎回ローテーションやビジュアル重視のサイズ設計を採用しています。
- **テンポと遊び心**: 公演詳細は誤タップで外部へ飛ばない「見るだけ」設計で連続閲覧しやすくし、スキマ探索の待機演出や活版×箔押し風のチケットパスでフェスならではの体験に仕上げています。

それぞれの詳しい意図（「なぜ合計金額や重複ロックを付けないのか」等）は [docs/DESIGN.md](docs/DESIGN.md) にまとめています。
