# Universal Timetable Core v3.0 設計仕様書

## 1. 概要
イベントや謎解きフェスティバル向けの汎用ハシゴ計画作成テンプレートです。Google スプレッドシート（GAS）で公演情報を管理し、静的 JSON（`public/data.json` / `mock_data.json`）または GAS Web API 経由で配信します。

## 2. 設計思想

このテンプレートの UI・機能には、「なぜ普通はありそうな機能を付けないのか」「なぜあえてこの挙動にしているのか」という明確な意図があります。今後の改修やカスタマイズでも、以下の軸を崩さないことを大切にしています。

### 2.1 「初心者が迷わない」＆「3行で説明できない機能は使われない」
- **トップ画面は最小限の情報だけ**: 最初の画面がごちゃごちゃすると初心者が混乱するため、上部バーは 1 行 3 ボタン、タイムテーブルのコマ内も「時刻＋メインビジュアル」に絞り、会場名や料金などは詳細・予定表へ逃がしています。
- **HOW TO USE は 3 ステップだけ**: 「見ずに触れそう」「触ってみたら使い方が分かる」「次にやることは視線誘導（選択時にせり出す下部バー）で自然に分かる」体験を目指し、細かい機能説明は載せていません。

### 2.2 すべての出展団体にスポットライトを当てる（機会均等と出会い）
- **団体名フィルター・列の非表示を置かない**: フェスが「有名団体の狙い撃ち」だけで終わらず、どの出展団体にも平等に目が向くよう、団体名で絞り込んだり列をワンクリックで隠したりする機能は設けていません。
- **メインビジュアルを極小スリム化しない**: テキストだけの細い表にすると知名度・団体名だけで選ばれがちになるため、出展者が力を入れて作ったビジュアルの魅力がしっかり届く標準サイズに一本化しています。
- **タグ順の黄金比ローテーション＆既プレイ除外の折りたたみ**: 絞り込みタグの表示順は毎回ローテーションして偏りを防ぎ、公演を見えなくする「既に参加済を非表示」はあえて最下部の折りたたみ内に控えめに置いています。「あ、こういう公演もあるんだ」という偶然の出会いを消さないための設計です。

### 2.3 主催・出展者全体の体験を守る「あえてやらないこと（Non-Goals）」
- **合計参加費の自動計算を出さない**: 合計金額が見えると心理的なブレーキがかかって予定追加が止まりやすくなるため、金額を意識させず「行きたい公演」ベースで楽しく計画を組んでもらう設計にしています。
- **重複枠を即時ロック（選択不可）しない**: 時間が被る公演を自動でクリック不可にすると比較できなくなるため、赤色の重複警告を出しつつ選べるようにし、予定表側でじっくり調整できるようにしています。

### 2.4 見る・探す・使うテンポへのこだわり
- **リング型詳細（`SpecPopup`）は「見るだけ」**: 色んな公演をパッパッと連続で見て回るとき、詳細内に予約ボタンがあると誤タップで別ページへ飛んでテンポが途切れてしまいます。外側タップで即閉じる／別の公演へすぐ切り替えられるよう、タップ位置を気にせずサクサク閲覧できる「見るだけ」の画面にしています（予約導線は「自分の予定・ハシゴ表」側に集約）。
- **ルート案内は事前 OFF・当日 ON**: 開催前日まで会場移動ルート案内は使われないため、事前計画中は初期 OFF にして一覧を見やすく保ち、開催当日だけはボタンを押す手間を 1 回省くため最初から ON にしています。

### 2.5 謎解きフェスらしい遊び心と手触り感
- **スキマ時間探索の待機演出**: プログラム上は一瞬で結果を出せますが、「探している感」やワクワクした面白さを味わってもらうため、あえて約 1.35 秒の「ナゾトキあるある」待機メッセージを挟んでいます。
- **活版印刷×箔押し風の「My ハシゴテーブル」**: 単なるテキスト一覧や味気ないスクショではなく、手元に記念として残したくなる・思わず X でシェアしたくなる「活版印刷×箔押しチケット」の質感にこだわっています。

## 3. バニラ版 v3.0 UX・UI 設計方針

### 3.1 ファーストビューの極簡化と視線誘導
- 上部スティッキーバーは **1行・3操作のみ**（`[? 使い方]`・`[< DAY N >]`・`[絞り込み・便利機能]`）に限定します。
- 選択 0 件時は下部選択バーを非表示にし、公演タップ時にのみ下部へ選択バーをせり出させて `[自分の予定・ハシゴ表を見る]` へ視線誘導します。
- `Plan A / B`・ヒートマップ送信・未実装エクスポート機能は廃止しています。

### 3.2 標準サイズ一本化と情報階層
- 表示サイズは視認性の高い標準サイズ（`138px` 列幅 / `74px/時`）へ統一し、サイズ切替UIは設けません。
- タイムテーブル上の各時間枠カードには **時刻のみ** を表示し、会場（場所）情報はクリック時の詳細ポップオーバーおよび「自分の予定・ハシゴ表」内に集約しています。
- カード左端の縦色ライン装飾は廃止し、均一枠・背景色・チェックバッジ・状態ラベルで視認性を確保しています。

### 3.3 「自分の予定・ハシゴ表」＆ スキマ時間探索
- モーダル起動直後は当日の選択公演一覧（重複警告・場所バッジ・予約ページ導線）のみをクリーンに表示します。
- 下部サブボタン `スキマ時間に入れる公演を探す` を押すと、最低 1 秒以上（標準 1.35 秒）の「ナゾトキあるある待機メッセージ（11種ローテーション）」を経てから、空き時間帯に収まる候補公演と `＋ 追加` ボタンを展開します。
- 移動バッファ判定：`設定` シートの `0分移動可否` が `0分移動NG` の場合、候補の前後各 5 分（`endMinutes + 5 <= cand.start` かつ `cand.end <= next.start - 5`、または随時受付は `durationMin + 10 <= gapMin`）の余裕を確保します。

### 3.4 「My ハシゴテーブル」＆ 共有保護
- リスト画面の主 CTA `My ハシゴテーブルを表示する` から黒基調パス画面へ遷移します。
- 下部操作は上段左 `予定をコピー`（テキスト一覧 ＋ `?plan=` 共有 URL）、上段右 `画像を保存`（`html-to-image` PNG 生成）、下段全幅 `Xでシェア` の 2 行 3 ボタン構成です。
- `?plan=` パラメータ付き URL を開いた場合は `#share-preview-banner` で共有プレビュー保護モードを起動し、閲覧者の既存 `localStorage` を上書きしません。

### 3.5 表示フィルタと既プレイ除外
- `#filter-dialog` 内で難易度（以上/以下）、黄金比オフセットで出現順が毎回ローテーションするタグ絞り込み、および最下部の折りたたみ `<details>` による「体験済み公演の除外」を提供します。

### 3.6 スプレッドシート「1.公演かんたん入力」E列（開始時間リスト）の記法
- **複数回の定時公演**: カンマ・読点・改行区切りで時刻を列挙します（例: `10:30, 12:00, 13:30`）。
- **終日の随時受付**: `随時` と記入します。
- **休止時間を挟む随時受付**: ハイフンまたは波ダッシュで時間帯レンジを複数指定します（例: `10:00-12:00, 13:00-18:00`）。GAS 展開時に開始時刻・受付終了時刻の複数行へ自動展開され、タイムテーブルの同列内に休止空白を挟んで複数枠が描画され、スキマ時間探索でも各受付時間帯のみが候補判定されます。

### 3.7 効果測定・利用レポート機能（スプレッドシート集計 ＋ GA4 連携）
- 一般参加者向けの Web UI は一切変更せず、裏側（`Analytics.js`）で訪問者ごとの予定選択・スキマ探索・画像保存・予定コピー・Xシェア・絞り込みタグタップを計測します。
- `設定` シートに `効果測定GAS URL`（GAS の Web アプリ `/exec` URL）を設定すると `doPost` で匿名集計を受信し、スプレッドシートの `利用レポート` シートに **全体利用サマリー**・**人気タグランキング（組込人数/延べ枠数/絞り込み回数）**・**公演別ハシゴ組込数ランキング** を自動集計します。
- あわせて `GA4測定ID`（`G-...`）を設定した場合は Google Analytics 4 へも同一イベントを同時送信します。

## 4. アーキテクチャ構成

```text
src/
├── main.js                   # アプリケーション統括・SWR読込・URL共有制御・テーマ適用
├── adapters/                 # StaticJsonAdapter / GasAdapter / MockAdapter
├── core/
│   ├── Analytics.js          # 効果測定（利用レポートGAS送信・GA4連携）
│   ├── Parser.js             # スプレッドシート日本語キー正規化・エスケープ
│   ├── ConflictDetector.js   # 時間重複・0分移動判定・前後5分バッファ付きスキマ探索
│   └── Storage.js            # plan_v3 / excluded_v3 / timetable_cache_v3・URLエンコード
├── ui/
│   ├── TimetableView.js      # 標準サイズ全体表描画・ロック解除トリガー・イベント委譲
│   ├── SelectionBar.js       # 選択追従バー・重複アラート表示
│   ├── SpecPopup.js          # 公演詳細（リング型：ポスターのまわりに難易度・所要時間と定員・料金・場所・タグ）
│   ├── FilterModal.js        # 難易度・機会均等タグ・折りたたみ除外リスト
│   ├── MyScheduleDialog.js   # 予定一覧・Now Loading・スキマ候補・パス切替統合モーダル
│   └── TicketView.js         # My ハシゴテーブル描画・テキストコピー・PNG保存・Xシェア
└── styles/
    ├── tokens.css            # 着せ替えカラー変数・固定タイムテーブル寸法トークン
    ├── main.css              # エントリCSS・Tailwind連携・scroll-state/基本挙動
    ├── timetable.css         # ヒーロー・1行ナビ・タイムテーブルグリッド・カード
    └── components.css        # 下部バー・モーダル・Loading・My ハシゴテーブル・フィルタ
```
