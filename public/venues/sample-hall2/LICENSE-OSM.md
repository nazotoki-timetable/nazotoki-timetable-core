# 屋外の地図データについて

`outdoor.svg` と、`venue_map.json` のうち屋外（`floor: "OUT"`）の点・道は、OpenStreetMap のデータをもとに作っています。

- 地図データ © OpenStreetMap contributors
- ライセンス：Open Database License（ODbL）1.0 — https://opendatacommons.org/licenses/odbl/1-0/
- 詳しくは https://www.openstreetmap.org/copyright

このデータ（屋外の点・道の座標）は、同じ ODbL 1.0 で利用できます。
「会場」「駅前広場」はサンプルの呼び名で、実在の施設の名前や催しとは関係ありません。
屋内のフロア図はサンプル用に作成した簡略図で、OpenStreetMap のデータではありません。
